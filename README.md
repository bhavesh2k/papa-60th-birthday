# Papa's 60th birthday site

A no-build static site designed for GitHub Pages.

## Personalize it

1. Replace the three `.photo-placeholder` blocks in `index.html` with image tags such as `<img src="assets/photo-1.jpg" alt="Papa with family">` and add your photos in an `assets` folder.
2. Replace the text in the `#personal-message` block with your note.
3. Update the timeline years and captions if you want to use it.
4. Optional music: place an MP3 in `assets/music.mp3`, then add an `<audio controls loop src="assets/music.mp3"></audio>` element. Browsers require the visitor to start audio, so a small music control is ideal.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Select `main` and `/ (root)`, then save. GitHub shows the live URL after deployment.
